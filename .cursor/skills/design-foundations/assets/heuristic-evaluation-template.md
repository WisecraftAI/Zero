## Per-heuristic checklist (prompts to find issues)

### 1. Visibility of system status
- [ ] Is loading / saving / processing visible?
- [ ] Do buttons confirm their action?
- [ ] Is current location in the product always clear?
- [ ] Are selections visibly selected?

### 2. Match real world
- [ ] Is language the user's (not internal jargon)?
- [ ] Are icons universally understood?
- [ ] Are date, currency, number formats localized?

### 3. User control and freedom
- [ ] Can users undo any action?
- [ ] Is there always a way out (back, cancel, close)?
- [ ] Are destructive actions confirmed or reversible?

### 4. Consistency and standards
- [ ] Same term for same concept throughout?
- [ ] Same pattern for same action?
- [ ] Follows platform conventions?

### 5. Error prevention
- [ ] Constrained inputs (pickers vs free text) where possible?
- [ ] Defaults reduce error-prone choices?
- [ ] Warn before irreversible actions?

### 6. Recognition over recall
- [ ] Options visible, not recalled?
- [ ] Recent / favorite / suggested items?
- [ ] Help inline near the input?

### 7. Flexibility and efficiency
- [ ] Shortcuts for power users?
- [ ] Bulk actions?
- [ ] Customization / saved states?

### 8. Minimalist design
- [ ] Every element earns its place?
- [ ] Decoration not competing with content?

### 9. Error messages
- [ ] Plain language, no codes?
- [ ] Identifies the problem and suggests a fix?
- [ ] Appears near the offending element?

### 10. Help and documentation
- [ ] Help findable in context?
- [ ] Empty states teach?
- [ ] Onboarding skippable and resumable?
