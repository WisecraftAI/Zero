# Research Plan Template

One-pager. If it needs to be longer, the scope is unclear.

## 1. Project and owner

- **Project:**
- **Research lead:**
- **Stakeholders:**
- **Timeline:** (kickoff → report)
- **Status:** draft / reviewed / approved / in-field / analysis / reported

## 2. Background

2-3 sentences. What prompted this research? What do we already know? What's been tried?

## 3. Research questions

The 3-5 things we need to learn. Ranked. Specific.

**Bad:** "Understand users."
**Good:** "How do current users of [product] currently complete [task]? Where do they get stuck? What workarounds do they use?"

## 5. Method

**Primary method:** (interview / usability test / survey / card sort / diary / etc.)

**Why this method:** (1 sentence tying to research questions)

**Format:** (moderated / unmoderated, remote / in-person, duration)

## 6. Participants

- **Target segment:** (behavior-based profile, not just demographics)
- **Sample size:** ___ per segment
- **Total:** ___
- **Screener criteria:**
  - Must: (behavioral qualifiers)
  - Must NOT: (exclusions - competitors, UX/design professionals, recent research participants)
- **Recruiting source:** (panel, customer list, snowball, agency)
- **Incentive:** $___ per participant

## 9. Analysis plan

- Note-taking: live in shared template, coded after
- Synthesis method: affinity mapping / coding / JTBD extraction
- Deliverable: (report / journey map / persona / insight doc / video highlights)

## 10. Ethics

- [ ] Participants informed of recording
- [ ] Consent collected
- [ ] PII handled per policy

- [ ] Compensation delivered

## 11. Success criteria for the research itself

The study succeeds if we can credibly answer each research question (or credibly state "we don't know yet") with specific, actionable findings.
