# 12-Week Foundational Curriculum for a Junior Designer

Designed for a junior with basic Figma skills and some exposure to design theory. Each week: one concept, one reading, one exercise, one critique session with a senior.

Adapt length based on learner pace. Some weeks combine; some stretch across two.

---

## Week 1: What is UX?

**Concept.** The difference between UX and UI. The design process.

**Reading.** Don Norman, *The Design of Everyday Things* (intro + chapter 1). Follow-up: "Principles of Design" by Norman & Nielsen.

**Exercise.** Audit three everyday objects (door, coffee machine, remote control). Identify affordances, signifiers, feedback, constraints. Write one page.

**Critique.** Present audit. Senior probes: "Why does that door fail? What does the user assume?"

## Week 2: UX laws and cognitive principles

**Concept.** Hick, Fitts, Miller, Jakob, Tesler, Gestalt laws, Cognitive load.

**Reading.** Laws of UX (Yablonski) - summary site and book.

**Exercise.** Pick a screen from any app. Annotate which laws are honored, which are violated. One-page memo with at least 8 annotations.

**Critique.** Defend the annotations. Senior pushes on "are you sure that's a violation? What would fix it?"

## Week 3: Research basics

**Concept.** Qualitative vs quantitative. Generative vs evaluative. Interview method. Think-aloud protocol.

**Reading.** Erika Hall, *Just Enough Research* (chapters 1-3).

**Exercise.** Conduct 3 user interviews on any topic (cooking, commuting, banking). Moderate neutrally. Summarize themes.

**Critique.** Read back sample quotes. Senior probes for leading questions, missed follow-ups.

## Week 4: IA and flows

**Concept.** Information architecture, sitemaps, task flows, user flows. OOUX intro.

**Reading.** Sophia Prater on OOUX; Dan Brown's "8 Principles of IA."

**Exercise.** Take a bloated product (pick one - LinkedIn, Amazon). Draw its current IA. Propose a reorganization. Justify.

**Critique.** Senior challenges: "Why would a user accept this change? What's the migration cost?"

## Week 5: Typography

**Concept.** Anatomy, classifications, scale, leading, measure, hierarchy.

**Reading.** Ellen Lupton, *Thinking with Type* (selected chapters). Butterick's *Practical Typography* online.

**Exercise.** Typography-only redesign: take a dense text page (article, annual report). Redesign with type alone - no color changes, no imagery. Two iterations.

**Critique.** Senior compares before/after. Discusses scale choices, measure, rhythm.

## Week 6: Color

**Concept.** Color models (RGB, HSL, OKLCH), harmony, semantic color, contrast, accessibility, dark mode.

**Reading.** Refactoring UI on color. Stripe Dashboard Design on color.

**Exercise.** Build a palette for a fictional product: 1 brand primary + neutral ramp + 4 semantic + dark mode. Show contrast pairings for body, large text, UI elements. All tokens named.

**Critique.** Senior stress-tests in multiple contexts. Checks contrast.

## Week 7: Layout and grids

**Concept.** Spacing scale, column grids, baseline grids, alignment, breakpoints.

**Reading.** Refactoring UI on layout. Every Layout (Heydon Pickering).

**Exercise.** Design the same screen (a product detail page) at 3 widths: 375, 768, 1440. Clearly show which columns and spacing tokens are used.

**Critique.** Senior reviews for consistency, hierarchy across breakpoints, intentional choices.

## Week 8: Components and design systems

**Concept.** Tokens, variables, variants, properties, slots. Three-tier architecture.

**Reading.** Material Design docs on tokens. Brad Frost's *Atomic Design*.

**Exercise.** Design 5 components (Button, Input, Card, Modal, Nav) with all states, all variants, all properties. Document with a props table.

**Critique.** Senior reviews each component. Looks for missing states, inconsistent naming, missing a11y.

## Week 9: Accessibility

**Concept.** WCAG, POUR, contrast, keyboard, screen readers, inclusive design.

**Reading.** WCAG 2.2 quick reference. Inclusive Components by Heydon Pickering.

**Exercise.** Run an accessibility audit on an existing product (theirs or a famous one). Use axe or WAVE. Fix 5 issues. Document before/after.

**Critique.** Senior does a keyboard-only walkthrough of their fix.

## Week 10: Interaction and motion

**Concept.** Affordance, signifiers, feedback, states, micro-interactions, motion principles.

**Reading.** Val Head's *Designing Interface Animation*. Material Motion guidelines.

**Exercise.** Take a static flow and design the motion for 3 key transitions. Prototype in Figma / Principle / Rive. Explain purpose of each: orient, confirm, guide attention.

**Critique.** Senior looks for motion that carries meaning vs decoration.

## Week 11: Critique and communication

**Concept.** How to give and receive critique. How to present work to stakeholders. Writing.

**Reading.** Aaron Irizarry & Adam Connor, *Discussing Design*.

**Exercise.** Observe a senior critique session. Take notes. Then lead a critique session on week 8's components.

**Critique.** Senior gives feedback on their moderation - neutrality, clarification vs. opinion, synthesis.

## Week 12: Capstone

**Concept.** Integration. End-to-end project.

**Assignment.** A small, bounded problem (e.g., "Redesign password reset flow for a banking app"). Deliver: research summary (even if small), IA/flow, key screens at 2 breakpoints, components from the system, accessibility notes, proposed metrics. 30-min presentation.

**Critique.** Panel review. Three seniors, structured feedback across all dimensions.

---

## After the 12 weeks

- **Month 4-6: Owned feature.** Real scope, mentor available.
- **Month 7-12: Scope expansion.** Cross-feature, or leading a small stream.
- **Year 2: Mid-level bar.** Independent on standard work, collaborating in design system, mentoring newer designers.

## Optional deep dives

After foundations, choose based on interest/path:

- **Product strategy** - JTBD, opportunity trees, OKRs.
- **Service design** - blueprints, multi-channel.
- **Content design** - voice, microcopy, IA writing.
- **Design ops** - tooling, process, governance.
- **Prototyping** - Framer, Principle, Rive, code.
- **Research specialization** - field methods, quant.
- **Specific verticals** - see `industry-design-patterns` skill.
